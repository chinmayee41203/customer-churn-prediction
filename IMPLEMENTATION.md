# Customer Churn Prediction System

## Project Overview
End-to-end ML project for predicting customer churn using Scikit-Learn, XGBoost, SHAP, PostgreSQL, and Streamlit.

## Phases
1. Data Collection
2. EDA
3. Data Cleaning
4. Feature Engineering
5. Model Training
6. Model Evaluation
7. Explainable AI (SHAP)
8. Risk Scoring
9. PostgreSQL Integration
10. Streamlit Dashboard
11. Testing
12. Deployment

## Deployment Steps
1. Create GitHub repository
2. Push code to GitHub
3. Create requirements.txt
4. Deploy on Streamlit Cloud
5. Connect repository
6. Select app.py
7. Deploy
